# [!DNL Adobe System Status] 发行说明 {#status-release-notes}

[!DNL Adobe System Status] 提供了关于 Adobe 产品与服务的详细信息、状态更新以及电子邮件通知。 获取有关故障、中断和维护活动的通知。 请在 [status.adobe.com](https://status.adobe.com/zh-cn/){target="_blank"} 上查看它。

此页面在一段时间内跟踪[!DNL Adobe System Status]更新。 仅当有要报告的新版本时才会更新。

| 日期 | 更新 |
| ------- | ------- |
| 2026年3月 | <ul><li>AI 虚拟助手测试版</li><li>错误修复和改进</li></ul> |
| 2025年12月8日 | <ul><li>虚拟助理反馈增强功能（简化的引导式工作流、直观图标）</li><li>错误修复和改进</li></ul> |
| 2025年7月16日 | <ul><li>虚拟助手全面可用</li><li>在Product和Cloud页面以及虚拟助理中搜索事件ID</li><li>Slack 通知设置更新</li><li>错误修复和改进</li></ul> |
| 2025年3月20日 | <ul><li>虚拟助手测试版</li><li>新事件术语表帮助页面</li><li>错误修复和改进</li></ul> |
| 2024年8月19日 | <ul><li>基于产品的维护通知（增强的UI和每个产品的通知）</li><li>错误修复和改进</li></ul> |
| 2024年4月11日 | <ul><li>用于设置主动通知配置文件和首选项的订阅帮助页面</li><li>通知改进（CSO通过电子邮件和Slack关闭通知）</li><li>错误修复</li></ul> |
| 2024年1月30日 | <ul><li>公告现在是状态API的一部分</li><li>界面性能改进</li></ul> |
| 2023 年 10 月 | <ul><li>新的“帮助”菜单及“概述/主页”的引导式浏览</li><li>状态API文档已更新为OAuth 2.0</li><li>错误修复（云页面横幅、已关闭事件电子邮件、重复事件、订阅可靠性）</li></ul> |
| 2023年7月18日 | <ul><li>公告：具有广泛影响的全球、云或产品级消息，现已作为订阅选项提供</li><li>性能和订阅增强功能</li><li>通知错误修复</li></ul> |
| 2023 年 3 月 | <ul><li>无新更新；请参阅2023年1月以了解最新功能（状态API）</li></ul> |
| 2023年1月19日 | <ul><li>Slack上现在可通过Adobe Status Slack应用程序使用状态通知</li></ul> |
